# Implementation progress

## 24 October 2026 - reviewed Windows beta preparation

- Replaced the default MCP route with direct skill scripts and a capability-authenticated persistent native service. Antigravity remains the model/agent.
- Fixed numeric-zero/indexed-focus behavior, observation settling, worker epochs, explicit completed-input/failed-verification evidence, idle expiry/recovery, UTF-8 streaming and legacy PowerShell output corruption.
- Persistent emergency Stop, per-input native fencing and independent owned-input/cursor recovery remain active. Keep working is the default requested by the owner.

- Refined the soft edge field and smaller halo. Removed decorative cursor noise; text fields have a distinct custom insertion cursor. Precomputed separable falloff avoids per-pixel exponential evaluation.
- 69 automated checks and the refreshed native/cursor/guardian/crash suites pass. First component hotkey conflict was retained and resolved by normal shutdown of the idle old service.
- Added manifest verification before installer writes, a corruption regression, provenance checking in CI and fresh-output packaging that preserves existing folders.
- Canonicalized source line endings to repository LF before native compilation/provenance hashing. The qualified helper is source-addressed and reused rather than forcibly recompiled for packaging.
