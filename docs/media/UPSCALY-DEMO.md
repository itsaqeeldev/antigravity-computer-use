installed direct `/computer-use` controller (beta.2 build
`23ddd7bdfc2f2c19060308c441ef7fef43d700ccfdccaa88b76bb488105d2777`).

from its verified release. The input was an owner-supplied sample photograph.

view. The selected model was General Real-World, and the app used 4×. The final

The controller receipts record successful window actions and normal End. The
agent reported native AI execution; independent process-level proof remains open.

speeds playback by 3×, and removes approximately three seconds containing the
native file picker to avoid exposing its sidebar. Output is a silent 960×598
MP4 of approximately 23 seconds, with an 8 fps 720-wide GIF derivative. Timing
and cuts mean this is not an end-to-end speed measurement. Earlier setup and wait
time are omitted. Raw desktop footage remains private under `.localdata`.
